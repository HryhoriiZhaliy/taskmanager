# Manager Task App

This is a Task Manager application with Firebase Realtime Database and Vercel deployment.

## Setup

1. Copy `.env.example` to `.env` and fill in your Firebase and admin credentials.
2. Install dependencies:
   ```
   npm install
   ```
3. Run local dev server:
   ```
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000)

## Deploy to Vercel

1. Push to GitHub.
2. Import the repository on Vercel.
3. Set environment variables in Vercel dashboard.
4. Deploy!
